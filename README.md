# Ahmad El Mufti, portfolio

Personal site: software engineer in Benghazi. Vite + vanilla HTML, CSS and JS, in English and Arabic (RTL).

## Run

```
npm install
npm run dev       # local dev server
npm run build     # production build into dist/
npm run preview   # serve the build
```

Add `?lang=ar` to the URL to open the Arabic version.

## Notes

- The project interfaces in the Work section are drawn in HTML with sample data.
- Archive pictures of Benghazi are public domain, via Wikimedia Commons; see `credits.json`.
